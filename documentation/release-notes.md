# Release notes

## 4.0.0
Geschikt gemaakt voor Valtimo 13.24.0 en ondergebracht in een eigen repository, met voorbeeldapplicatie en aparte documentatie.

Authenticatie naar Suwinet wordt nu via de aparte Suwinet Auth-plugin geregeld en ondersteunt extra koppelingen zoals bijstandsregelingen.

## 3.0.0
